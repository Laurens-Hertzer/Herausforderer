## Pitch

### Produkt / Kurzbeschreibung
Es ist eine App, in der man verschiedene Herausforderungen abschliessen muss. Sie beginnen wie bei bop-it, gehen aber schnell weiter weg in verrücktere Szenarien.
### Zielgruppe
Leute die sich bewegen möchten und für soziale Aktivitäten.
### Unique Value Proposition
Hat den Thrill von Herausforderungsspielen, wie "Truth or Dare», wo man sich beweisen muss.
### Preisstrategie
Free, die Idee ist es auf meiner Portfolioseite es zu haben und eine Promotion von mir selber zu sein.
### Distribution / Placement
Portfoliowebsite und Stores, bei denen man nicht für das Hochladen zahlen muss, wie z.B. App Store
### Promotion-Massnahmen
Projekt auf der Portfoliowebsite
Nachricht im KBW-Team
### Minimal erforderliche Hauptfunktionalitäten
Sensorenabfragen
10 Szenarien
Leaderboard/Points

## Starten

1. Dependencies installieren

   ```bash
   npm install
   ```

2. App starten

   ```bash
   npx expo start
   ```

In der Ausgabe finden Sie möglichkeiten zum Ansehen der Applikation.

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go)

Ich empfehle Expo Go auf dem Handy zu installieren und dann über den QR-Code die Applikation zu öffnen.
